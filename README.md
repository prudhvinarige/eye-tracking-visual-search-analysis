# Predicting Visual Search Efficiency Using Eye-Tracking Data

## Overview
This project analyzes eye-tracking data to understand user attention patterns and predict visual search efficiency in Human Computer Interaction (HCI) environments.

## Problem Statement
Traditional usability testing methods struggle to quantify user attention effectively. This project uses eye-tracking data and machine learning to provide actionable UI insights.

## Objectives
- Analyze gaze behavior
- Generate Heatmaps
- Visualize Scanpaths
- Predict Search Efficiency
- Improve User Interface Design

## Technologies Used
- Python
- NumPy
- Pandas
- OpenCV
- Matplotlib
- Scikit-Learn
- Google Colab

## Methodology
1. Data Preprocessing
2. Coordinate Normalization
3. Heatmap Generation
4. Scanpath Visualization
5. Machine Learning Classification

## Results
- Identified user attention hotspots
- Generated visual search patterns
- Predicted search efficiency using gaze features

## Future Work
- Deep Learning Models (LSTM, Transformers)
